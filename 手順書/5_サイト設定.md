# サイト設定

Pages CMSの左のメニューの「**サイト設定**」で、サイト全体の設定を変えられます。

| 項目 | 使われる場所 |
|---|---|
| 作者名 | トップページ左上の作者ページへのリンク、作者ページ、各ページ下の著作権表示 |
| 自己紹介 | 作者ページ |
| 作者ページにリンクを追加 | 作者ページ（Xや購入先、作家仲間のサイトなど。`https://` から始まるアドレス。下の「作家仲間との相互リンク」も見てください）。「リンクの上に表示する文」を入れると、そのリンクの上に説明が出ます（例：「〇〇の購入は下のサイトから」） |
| XのユーザーID | 読者が作品をXでシェアしたときにあなたに通知が届きます。作者ページにもXへのリンクが付きます |
| サイト名・サイトの説明文 | ブラウザのタブ、検索結果、リンクがXやLINEなどに貼られたとき |
| リンクが貼られたときの画像 | リンクがXやLINEなどに貼られたときに大きく表示される画像（サイト共通の1枚）。表紙のある小説や、漫画・イラストのページでは、その作品の画像が優先されます |
| サイトのURL | Xでシェアされるリンクや、検索エンジンに伝えるアドレス。独自ドメインがなければ、Cloudflareで発行された `○○.workers.dev` のアドレス |
| AIによる読み取りを断る | 下の「AIによる読み取りについて」を見てください |

## 作家仲間との相互リンク

交流のある作家とお互いのサイトを紹介し合うと、あなたの読者が仲間の作品を、仲間の読者があなたの作品を見つけるきっかけになります。お互いに「作者ページにリンクを追加」から相手のサイトを載せてください。

ただし、検索で上に出ることを目当てに、よく知らない相手と大勢でリンクを張り合うのはやめてください。Googleはこれを禁止していて、かえって検索結果に出にくくなることがあります。載せるのは、読者にすすめたいと思える相手だけにしましょう。

## AIによる読み取りについて

サイトには、AIに関係する2つのファイルが自動で作られます。

- **llms.txt**：AI向けの作品の案内です。サイト名・作品の一覧・あらすじを短くまとめたもので、ChatGPTなどのAIがあなたのサイトについて聞かれたときに、正しく紹介しやすくなります。ただし公式の決まりではなく、読むかどうかはAIを運営する会社しだいです。
- **robots.txt**：サイトを読みに来るプログラム（検索エンジンやAIの会社のもの）に、読んでよいかを伝えるファイルです。初めの設定では、どのプログラムにも「読んでよい」と伝えています。

作品をAIに読まれたくない場合は、「サイト設定」の「**AIによる読み取りを断る**」をオンにしてください。

- robots.txt で、ChatGPT・Claude・Gemini・Perplexityなどを運営する会社の読み取りプログラムに「読まないで」と伝えます
- llms.txt を作らなくなります。ChatGPTなどのAIに、あなたのサイトの作品を紹介してもらいにくくなります
- GoogleやBingなどの検索結果には、これまでどおり表示されます

知っておいてほしいこと：

- 「読まないで」と**求めるだけ**で、止める力はありません。従うかどうかは各社しだいです（OpenAI・Anthropic・Googleなどは従うと公表しています）
- 検索結果の上に出るAIの要約（GoogleのAIによる概要など）は、検索と同じプログラムが読んでいるため、この設定では断れません。断るには検索結果からも消えることになります
- オンにする前に読まれた分は取り消せません。気になる場合は、作品を載せる前にオンにしてください
