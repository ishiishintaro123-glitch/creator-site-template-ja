# サイトの立ち上げ

最初に一度だけ行う作業です。30分ほどかかります。費用はかかりません（独自ドメインを使う場合だけ、ドメイン代がかかります）。

## 用意するもの

- **GitHubのアカウント**：サイトのファイル一式（作品・画像・設定）の置き場です。[github.com](https://github.com) で作れます
- **Cloudflareのアカウント**：サイトを公開する場所です。[dash.cloudflare.com](https://dash.cloudflare.com/sign-up) で作れます。無料プランのままで使えます

どちらも、乗っ取られるとサイトを書き換えられてしまうので、2段階認証を設定しておいてください。

## 1. 自分のリポジトリを作る

1. このテンプレートのページ（GitHub）で、右上の「**Use this template**」→「**Create a new repository**」を押します。
2. 「Repository name」に、リポジトリの名前を半角英数字で入れます（例：`my-novel-site`）。サイトのアドレスにはならないので、自分で分かる名前でかまいません。
3. 「**Private**」を選びます。公開前の作品をGitHub上で他の人に見られないようにするためです。
4. 「**Create repository**」を押します。

## 2. Cloudflareで公開する

1. Cloudflareのダッシュボードを開き、左のメニューの「**Workers & Pages**」→「**作成**」を押します。
2. 「**リポジトリをインポート**」を選び、GitHubと連携します。
3. GitHubの画面で、CloudflareのGitHubアプリ（Cloudflare Workers and Pages）にアクセスを許可します。このとき「**Only select repositories**」を選び、**1で作ったリポジトリだけ**を選んでください。このアプリはリポジトリの管理の権限も求めるので、ほかのリポジトリまで許可しないでください。
4. Cloudflareの画面に戻り、1で作ったリポジトリを選びます。
5. 設定を次のとおりにして、デプロイ（公開）します。
   - プロジェクト名：`creator-site` のまま（変える場合は、リポジトリの `wrangler.jsonc` の `name` も同じ名前に変えてください）
   - ビルドコマンド：`npm run build`
   - デプロイコマンド：`npx wrangler deploy`
6. 数分待つと公開されます。サイトのアドレス（`https://creator-site.○○.workers.dev`）が表示されるので、控えておいてください。

## 3. サイトの設定をする

1. [Pages CMSで作品を投稿する](1_作品の投稿.md)の「はじめて使うとき」のとおりに、Pages CMSにログインします。
2. 左のメニューの「**サイト設定**」を開き、次の項目を書き換えて「**Save**」を押します。
   - サイトのURL：2で控えたアドレス
   - サイト名・作者名・サイトの説明文
3. 5〜10分ほどでサイトに反映されます。

ほかの項目は[サイト設定](5_サイト設定.md)を見てください。

サイトには、表示の確認用のサンプル作品が入っています。自分の作品を載せたら、Pages CMSでサンプル作品を削除してください。

## 独自ドメインを使う（任意）

`○○.workers.dev` の代わりに、自分で取ったドメイン（`example.com` など）でサイトを公開できます。

1. Cloudflareでドメインを取得するか、ほかで取得したドメインをCloudflareに追加します。
2. Workers & Pagesで自分のサイトを開き、「**設定**」→「**ドメインとルート**」で「**追加**」→「**カスタムドメイン**」を選び、ドメインを入れます。
3. Pages CMSの「サイト設定」で、サイトのURLを新しいドメイン（`https://example.com`）に変えます。
