# 手順書

サイトの立ち上げ方と、立ち上げたあとの使い方をまとめています。知りたいことのページを開いてください。

0. [サイトの立ち上げ](0_サイトの立ち上げ.md) — 最初に一度だけ。自分のリポジトリを作り、Cloudflareで公開する。独自ドメイン・予約投稿・ビルドキャッシュ（任意）
1. [Pages CMSで作品を投稿する](1_作品の投稿.md) — 小説・漫画・イラストの追加、話の追加、並べ替えの注意
2. [本文の書き方](2_本文の書き方.md) — 改行と段落、URLやリンクの入れ方
3. [原稿をまとめて取り込む](3_原稿の取り込み.md) — 書きためた原稿ファイルを一度に話として追加する
4. [画像](4_画像.md) — おすすめのサイズ、使われていない画像のお知らせと消し方、画像の量の上限
5. [サイト設定](5_サイト設定.md) — サイト名、作者ページ、リンクが貼られたときの画像、AIによる読み取り
6. [広告](6_広告.md) — 広告コードの貼り方と、プライバシーポリシーの確認

## AIに聞く

手順書をAIに読み込ませると、自分の言葉で質問できます。Gemini Notebook（無料）なら、次のようにします。

1. Gemini Notebookで新しいノートブックを作り、「ソースを追加」に次のURLを貼ります。手順書の全ページをまとめたものです。
   `https://raw.githubusercontent.com/ishiishintaro123-glitch/creator-site-template-ja/main/guide-for-ai.txt`
2. ノートブックの「カスタム指示」に次の文を入れます（任意）。答えが手順書に沿いやすくなり、どのページをもとにした答えかも書かれるので、手順書で確かめやすくなります。

   ```
   あなたは、このノートブックのソース（作品サイトのテンプレートの手順書）にもとづいて、技術に詳しくないクリエイターの質問に答える案内役です。
   - 手順書にある手順とボタンの名前をそのまま使い、順番どおりに、やさしい言葉で説明してください。専門用語を使うときは、短く説明を添えてください。
   - 手順書に書かれていないことは推測で答えず、「手順書には書かれていません」と伝えてください。
   - 答えの最後に、もとにした手順書のページ名（例：0_サイトの立ち上げ）を書いてください。
   - 合鍵になるアドレスを人に見せないなど、安全に関わる注意があるときは、必ず伝えてください。
   - テンプレートのIssuesを案内するのは、不具合の報告と、手順書の分かりにくい所の報告のときだけにしてください（使い方の個別の質問には、作者は答えていません）。
   ```

3. 「予約投稿の設定のしかたを教えて」のように、知りたいことを質問します。画面のスクリーンショットを一緒に追加して聞くこともできます。

URLを貼れないAIでは、上のURLを開いて保存したファイルを読み込ませてください。カスタム指示の欄がないAIでは、2の文を最初に送ってから質問してください。

AIの答えは間違っていることがあります。手順書と違うときは、手順書が正しいです。また、このURLは最新の手順書です。自分のサイトを作ったあとに手順書が更新されていて、自分のリポジトリの手順書と違うときは、自分のリポジトリの手順書に従ってください。

## 困ったときは

不具合の報告は、このテンプレートの[Issues](https://github.com/ishiishintaro123-glitch/creator-site-template-ja/issues)で受け付けています（あなたのサイトのリポジトリのIssuesではありません）。個人で開発しているため、対応までお時間をいただくことや、対応できない場合があります。個別の使い方のご質問にはお答えできないため、この手順書をご覧ください。

手順書の分かりにくい所や、書いてあるとおりに進まなかった所は、ぜひ[Issues](https://github.com/ishiishintaro123-glitch/creator-site-template-ja/issues)で教えてください。個別にお答えする代わりに、手順書を直して、次に読む人にも分かるようにします。どのページのどの部分か、書いてあると助かります。
