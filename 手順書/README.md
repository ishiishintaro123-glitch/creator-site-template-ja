# 手順書

サイトの立ち上げ方と、立ち上げたあとの使い方をまとめています。知りたいことのページを開いてください。

0. [サイトの立ち上げ](0_サイトの立ち上げ.md) — 最初に一度だけ。自分のリポジトリを作り、Cloudflareで公開する。独自ドメイン・予約投稿・ビルドキャッシュ（任意）
1. [Pages CMSで作品を投稿する](1_作品の投稿.md) — 小説・漫画・イラストの追加、話の追加、並べ替えの注意
2. [本文の書き方](2_本文の書き方.md) — 改行と段落、URLやリンクの入れ方
3. [原稿をまとめて取り込む](3_原稿の取り込み.md) — 書きためた原稿ファイルを一度に話として追加する
4. [画像](4_画像.md) — おすすめのサイズ、使われていない画像のお知らせと消し方、画像の量の上限
5. [サイト設定](5_サイト設定.md) — サイト名、作者ページ、リンクが貼られたときの画像、AIによる読み取り
6. [広告](6_広告.md) — 広告コードの貼り方と、プライバシーポリシーの確認

## 困ったときは

不具合の報告は、このテンプレートの[Issues](https://github.com/ishiishintaro123-glitch/creator-site-template-ja/issues)で受け付けています（あなたのサイトのリポジトリのIssuesではありません）。個人で開発しているため、対応までお時間をいただくことや、対応できない場合があります。個別の使い方のご質問にはお答えできないため、この手順書をご覧ください。
