# 本文の書き方

## 改行と段落

- 改行は、書いたとおりに表示されます。
- 空行を1行入れると、段落の区切りになります（少し間が空きます）。

## URLとリンク

URLはそのまま貼ればリンクになります。作品のあとに購入先を案内するときなどに使えます。

```
購入はこちら（https://example.booth.pm/items/123）です。
```

URLの直後に日本語を続けても、リンクは日本語の手前で止まります。同じ行に2つ並べてもかまいません。

文字をリンクにしたいときは、次のように書きます。

```
[BOOTHで購入する](https://example.booth.pm/items/123)
```

ほかのサイトへのリンクは、読者が小説のページに戻りやすいよう、新しいタブで開きます。

本文にHTMLのタグを書いても、そのまま文字として表示されます（ページの一部としては動きません）。
